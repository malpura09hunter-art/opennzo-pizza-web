01 — Homepage index.html

What is used: HTML5 provides the structure and CSS3 provides the visual presentation. The page uses semantic layout elements, navigation links and shared styling so the homepage follows the same design system as the rest of OPENNZO.

HTML tags

<header> holds the site header, <nav> holds navigation, <main> holds primary content, <section> divides content, and headings/paragraphs provide the text hierarchy.

<header><nav><main><section><h1><p><a>

Why these are used

Semantic HTML makes the structure easy to understand: navigation is separated from page content, sections group related information, and headings communicate the hierarchy of the page.

<link rel="stylesheet" href="style.css">

<nav aria-label="Primary navigation">
  <a href="index.html">Home</a>
  <a href="menu.html">Menu</a>
  <a href="orders.html">Pizza Orders</a>
  <a href="explanation.html">Explanation</a>
</nav>

Explanation: The <link> element connects HTML to the shared CSS file. The navigation uses <nav> and <a> so users can move between the separate HTML pages.

02 — Menu Page menu.html

The menu page uses HTML content blocks for pizza items and CSS layout rules to keep those blocks aligned. Cards can be arranged using Grid or Flexbox, while padding, borders and radius control their visual appearance.

HTML structure

<section> groups the menu area, <article> represents an independent menu item, and headings and paragraphs describe the item.

CSS design

Grid/Flexbox controls alignment; gap controls space between items; padding controls internal space; border-radius creates rounded corners; and hover/transition rules create smooth interaction.

03 — Pizza Orders orders.html

This page demonstrates semantic HTML form controls. The existing form elements are used to collect order information without replacing the existing functionality.

Form tags

<form><label><input><select><option><textarea><button>

Simple explanation: label identifies a field, input accepts short information, select/option creates choices, textarea accepts longer text, and button provides the form action.

Form styling

CSS controls field width, padding, borders, spacing, focus states and button appearance. Responsive rules prevent the form from becoming wider than the screen.

04 — Feedback feedback.html

The feedback page uses the same form concepts as the order page. Its purpose is to collect user feedback while maintaining the OPENNZO visual system through the shared stylesheet.

HTML

Form controls such as labels, inputs, text areas and buttons provide the structure for user-entered feedback.

CSS

Consistent spacing, borders, typography and responsive sizing make the form readable on desktop and mobile screens.

05 — Our Team team.html

The team page uses an <article> for each member. CSS Grid keeps the cards aligned, Flexbox arranges content inside each card, and responsive media queries change the number of columns on smaller screens.

<article class="team-card">
  <span class="roll-badge">ROLL NO. 204</span>
  <h3>Parth Shinde</h3>
  <p class="team-role">Project Team Member</p>
  <a href="mailto:parth.shinde9870@gmail.com">
    SEND EMAIL →
  </a>
</article>

Explanation: <article> makes the member a separate content block, <span> displays the roll badge, <h3> displays the name, and mailto: creates an email action. CSS Grid controls the overall card arrangement while Flexbox controls the internal layout.

CSS3 is responsible for the visual design of OPENNZO. These properties are used to control layout, spacing, typography, cards, interaction and responsive behavior.

08 — Animations CSS3

OPENNZO's visible entrance effects are implemented with CSS animation rules. The animation is not automatically a JavaScript animation; @keyframes defines the movement and the animation property applies it.

@keyframes teamFadeUp {
  from {
    opacity: 0;
    transform: translateY(18px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.team-card {
  animation: teamFadeUp .55s ease both;
}

How to explain it: @keyframes defines the start and end states. opacity controls visibility. translateY() moves the card vertically. animation connects the card to the defined animation and controls its duration and timing.

09 — Responsive Design CSS Media Queries

Responsive design makes the same website adapt to different screen sizes. OPENNZO uses CSS media queries to change layouts instead of requiring a separate mobile website.

@media (max-width: 700px) {
  .team-grid {
    grid-template-columns: 1fr;
  }
}

Explanation: When the viewport becomes 700px wide or smaller, the team grid changes to one column. The same approach can be used for other page layouts so content remains readable without horizontal scrolling.
