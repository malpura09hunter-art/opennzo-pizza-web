OPENNZO • COMPLETE REFERENCE • HTML5

Every HTML tag
used in OPENNZO.

This reference explains the actual HTML elements used by the project, what each one does, and how that element appears in the OPENNZO webpage. The examples are based on the project's implementation rather than unrelated textbook examples.

<!DOCTYPE html>

Purpose: Tells the browser to use modern HTML standards. OPENNZO: It is the first declaration in index.html.

<!DOCTYPE html>
<html>

Purpose: Root element of the document. OPENNZO: <html lang="en"> identifies the page language.

<head>

Purpose: Holds metadata and resources. OPENNZO: Contains the viewport, description, title and CSS link.

<meta>

Purpose: Supplies metadata. OPENNZO example: <meta name="viewport" content="width=device-width, initial-scale=1.0">.

<title>

Purpose: Browser tab title. OPENNZO example: OPENNZO — Fresh. Hot. Unforgettable..

<link>

Purpose: Connects an external resource. OPENNZO: <link rel="stylesheet" href="style.css"> connects CSS.

<body>

Purpose: Contains visible webpage content. OPENNZO: All restaurant sections are inside the body.

<header>

Purpose: Introductory/header content. OPENNZO: The site header contains the navigation and brand.

<nav>

Purpose: Groups navigation links. OPENNZO example: <nav class="nav container" aria-label="Primary navigation">.

<main>

Purpose: Primary page content. OPENNZO: Hero, About, Menu, Orders, Feedback, Team, Contact and documentation are main content.

<section>

Purpose: Groups related content. OPENNZO: Sections use IDs such as id="menu" so navigation can target them.

<article>

Purpose: Represents a self-contained content item. OPENNZO: Used for feature, pizza, team and documentation cards.

<div>

Purpose: Generic structural container when no more semantic element fits. OPENNZO: Used for layout wrappers and card content groups.

<span>

Purpose: Small inline container. OPENNZO: Used in the brand for the decorative dot and in labels/eyebrows.

<h1>

Purpose: Main page heading. OPENNZO: The primary hero brand/title uses the highest heading level.

<h2>

Purpose: Major section heading. OPENNZO: Used for headings such as “MORE THAN JUST PIZZA”.

<h3>

Purpose: Subsection/card heading. OPENNZO: Used for pizza names, feature titles and documentation topics.

<p>

Purpose: Paragraph text. OPENNZO: Used for descriptions, project information and explanatory content.

<a>

Purpose: Creates hyperlinks. OPENNZO example: <a href="#menu">EXPLORE MENU</a> jumps to the menu.

<img>

Purpose: Displays an image. OPENNZO: Pizza images use src and meaningful alt text.

<ul>

Purpose: Unordered list. OPENNZO: Available wherever grouped content is represented as a list.

<ol>

Purpose: Ordered list. Use when sequence matters, such as numbered presentation steps.

<li>

Purpose: Individual item inside ul or ol. It provides the content of a list entry.

<form>

Purpose: Groups user-input controls. OPENNZO: Used for the pizza order and feedback forms.

<label>

Purpose: Names a form control and improves accessibility. OPENNZO: Labels are connected to controls using for and id.

<input>

Purpose: Single-value form control. OPENNZO: Demonstrates text, email, tel, number, time, radio and checkbox types.

<select>

Purpose: Dropdown selection. OPENNZO: Pizza, size and crust choices use select controls.

<option>

Purpose: Choice inside a select. OPENNZO: Each pizza/size/crust choice is represented by an option.

<textarea>

Purpose: Multi-line text input. OPENNZO: Used for special instructions and feedback.

<button>

Purpose: Interactive button. OPENNZO: Used for order/submit actions and styled as a CTA.

<fieldset>

Purpose: Groups related form controls. OPENNZO: Useful for related options such as pizza size or extras.

<legend>

Purpose: Gives a fieldset its caption. It makes grouped choices understandable.

<footer>

Purpose: Closing/footer content. OPENNZO: Contains project identity and presentation information.

<strong>

Purpose: Marks text as strongly important. OPENNZO: Used to emphasize technology names and important documentation labels.

<em>

Purpose: Emphasized text. OPENNZO: Used for visual emphasis in headings such as “Fresh. Hot. Unforgettable.”

<br>

Purpose: Creates a line break. OPENNZO: Used sparingly where a deliberate text line break is part of the composition.

<code>

Purpose: Marks inline computer code. OPENNZO: Used throughout documentation for tags, attributes, filenames and CSS selectors.

<pre>

Purpose: Preserves whitespace and line breaks. OPENNZO: Used for formatted source-code presentation.

HTML ATTRIBUTES

Every important
attribute.

id

Unique identifier. <section id="menu"> lets href="#menu" navigate directly to the menu.

class

Reusable styling hook. class="pizza-card" allows CSS to style all pizza cards consistently.

href

Link destination. <a href="#orders">ORDER</a> moves to the orders section.

src

Resource path. <img src="assets/images/pizza.jpg" ...> tells the browser where the image is.

alt

Alternative image description. Example: alt="Fresh OPENNZO Margherita pizza".

type

Defines control behaviour. Examples: type="email", type="radio", type="checkbox", type="submit".

name

Names a form value. Radio buttons sharing a name behave as one choice group.

placeholder

Shows an input hint, for example placeholder="Enter your name".

required

Marks a form field as mandatory and enables browser validation.

value

Defines the value represented by a radio, checkbox or other form control.

for

Connects a label to the control whose id matches it: <label for="email">.

aria-label

Provides an accessible name where visible text is not sufficient. OPENNZO uses it on navigation and the CSS-only menu control.

lang

Declares document language: <html lang="en">.

rel

Describes a relationship between documents/resources. OPENNZO uses rel="stylesheet" on the CSS link.

content / name

Used by meta elements to provide viewport and description metadata.

FORM REFERENCE

Form tags
in the real page.

Actual structure pattern

<form>
  <label for="customer-name">Customer Name</label>
  <input id="customer-name" name="customer-name" type="text" required>

  <label for="pizza">Pizza Selection</label>
  <select id="pizza" name="pizza">
    <option value="margherita">Classic Margherita</option>
    <option value="farmhouse">Farmhouse</option>
  </select>

  <fieldset>
    <legend>Size</legend>
    <label><input type="radio" name="size" value="medium"> Medium</label>
    <label><input type="radio" name="size" value="large"> Large</label>
  </fieldset>

  <label><input type="checkbox" name="extra-cheese" value="yes"> Extra Cheese</label>
  <label for="instructions">Special Instructions</label>
  <textarea id="instructions" name="instructions"></textarea>
  <button type="submit">Place Demo Order</button>
</form>

How to explain it: The form is the container. Labels identify controls. Inputs collect typed or selected values. Select/option provide dropdown choices. Fieldset/legend group related controls. Textarea collects longer text. Button provides the action.

CSS properties &
how OPENNZO uses them.

color

Sets text color. OPENNZO uses it to create readable cream/dark text hierarchy.

color: var(--ink);

background / background-color

Sets section/card backgrounds and the brand palette.

background: var(--cream);

font-family

Controls typeface. Used globally for the OPENNZO typography system.

font-size

Controls text scale for hero headings, sections, body copy and UI labels.

font-weight

Controls visual emphasis such as regular, medium and bold text.

line-height

Controls vertical space between lines for readable paragraphs.

letter-spacing

Controls spacing between characters, especially useful for uppercase labels.

margin

Creates space outside an element, separating sections and cards.

padding

Creates internal space between content and an element's edge.

border

Creates an edge around cards and controls.

border-radius

Rounds corners on cards, buttons, inputs and image containers.

box-shadow

Adds depth to UI components without images.

width / max-width

Controls element width and prevents content from becoming too wide.

height / min-height

Controls or protects the vertical size of components and sections.

display

Controls layout mode, such as block, flex or grid.

gap

Creates consistent spacing between Flexbox/Grid children.

CSS LAYOUT

Flexbox, Grid &
positioning.

display: flex

Creates a flexible one-dimensional layout. OPENNZO uses Flexbox for navigation alignment, button groups and card content.

flex-direction

Controls whether flex children run in a row or column.

justify-content

Controls distribution along the main axis.

align-items

Aligns items on the cross axis.

flex-wrap

Allows items to move onto additional lines when needed.

display: grid

Creates a two-dimensional layout. OPENNZO uses Grid for pizza, feature and team cards.

grid-template-columns

Defines the number and size of Grid columns. Responsive rules change the columns on smaller screens.

position: relative

Creates a positioning context for absolutely positioned decorative elements.

position: absolute

Positions an element relative to its positioned ancestor; useful for decorative hero elements and image composition.

position: sticky

Allows a navigation/header element to remain visible within its scrolling context when implemented.

z-index

Controls stacking order when positioned elements overlap.

overflow

Controls how content that exceeds a box is handled; useful for keeping code and images contained.

CSS INTERACTION

Transitions,
transforms & animations.

transition

Smoothly changes a property between states. Example concept: transition: transform .3s ease, box-shadow .3s ease; for cards/buttons.

transform

Changes an element's visual position or scale without changing normal document flow. OPENNZO can use translateY() for card lift and scale() for image hover.

opacity

Controls transparency and can be used for subtle decorative states.

animation

Connects an element to CSS keyframes. OPENNZO uses CSS-only animation for subtle decorative movement.

@keyframes

Defines the stages of a CSS animation, for example moving or fading a decorative element.

:hover

Targets an element while the pointer is over it. OPENNZO uses hover for buttons, links and cards.

:focus-visible

Provides a visible keyboard focus state so users can see which control is active.

::before / ::after

Pseudo-elements create decorative generated content without extra HTML where appropriate.

RESPONSIVE CSS

How the page
adapts to mobile.

@media

Media queries apply different CSS rules at different viewport sizes. OPENNZO uses them to change grids, spacing, navigation and typography.

Responsive Grid

Desktop can show several cards per row; smaller screens reduce the number of columns so content remains readable.

Responsive navigation

The CSS-only navigation control uses HTML plus CSS instead of JavaScript to adapt the menu on small screens.

Responsive forms

Form columns collapse and controls become easier to use on narrow screens.

Teacher-friendly answer

“Responsive design means the same webpage adapts to different screen sizes. In OPENNZO, CSS media queries change the grid, navigation, spacing, typography and form layout so the site remains usable on desktop, tablet and mobile.”
