02 • HTML

What is HTML?

HTML stands for HyperText Markup Language. It is the markup language used to create the structure and meaning of a webpage. HTML tells the browser what content exists — headings, paragraphs, images, links, sections, forms and other elements. In OPENNZO, HTML creates the restaurant structure while CSS controls how that structure looks.

<section>
  <h2>More Than Just Pizza</h2>
  <p>Fresh ingredients and bold flavours.</p>
</section>
Simple presentation answer: “HTML creates the structure of the webpage. In OPENNZO it is used for the navigation, headings, paragraphs, images, pizza cards, forms, team information and footer.”

04 • HTML ATTRIBUTES

Attributes used in the project

id

Uniquely identifies an element. Used for section targets and specific elements.

class

Assigns reusable styling or grouping. CSS classes control the OPENNZO visual system.

href

Specifies the destination of an anchor. Example: href="menu.html".

src

Specifies the source of an image or other resource.

alt

Provides meaningful alternative text for images.

type

Defines the type of an input or button, such as email, number, radio or submit.

name

Identifies a form control as part of form data.

placeholder

Shows a short hint inside an empty input.

required

Marks a form control as required before submission.

value

Defines the value associated with a form control.

05 • FORMS

Which tags are used in the forms?

The Pizza Orders and Feedback pages demonstrate a complete semantic form structure.

<form>
  <label for="name">Customer Name</label>
  <input id="name" name="name" type="text" required>

  <label for="pizza">Pizza Selection</label>
  <select id="pizza" name="pizza">
    <option>Classic Margherita</option>
    <option>Paneer Tikka</option>
  </select>

  <label for="notes">Special Instructions</label>
  <textarea id="notes" name="notes"></textarea>

  <button type="submit">Place Order</button>
</form>
form

Groups all controls belonging to the form.

label

Connects visible text with a specific control.

input

Collects short values such as name, email, phone or quantity.

select + option

Creates a predefined choice list.

textarea

Collects longer written information.

button

Provides the form action control.

06 • CSS

What is CSS?

CSS stands for Cascading Style Sheets. CSS controls the presentation of HTML. In OPENNZO, CSS is responsible for colours, typography, spacing, cards, buttons, Grid, Flexbox, responsive layouts, hover effects, transitions and animations.

.menu-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

.menu-card:hover {
  transform: translateY(-6px);
  transition: transform .25s ease;
}
Simple presentation answer: “CSS is used to style HTML. In OPENNZO, CSS controls the layout, colours, typography, spacing, responsive design, cards, buttons, hover effects and animations.”
