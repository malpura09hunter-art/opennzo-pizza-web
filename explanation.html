01 / INTRODUCTION

What is OPENNZO?

OPENNZO is a demo pizza restaurant webpage made by the OPENNZO Team for a Web Programming practical and presentation. It combines a real product-style restaurant interface with an educational demonstration of HTML5 and CSS3.

Objective

The objective is to demonstrate webpage structure, semantic HTML, forms, links, images, CSS styling, Flexbox, Grid, responsive design, transitions, transforms and accessibility without JavaScript.

About the source code

The authoritative implementation is the project's GitHub source: index.html contains the webpage structure and style.css contains the visual system, layout, responsive rules and CSS interactions.

02 / HTML FUNDAMENTALS

What is HTML?

Definition

HTML means HyperText Markup Language. It is the markup language used to define the structure and meaning of webpage content.

HTML in OPENNZO

HTML creates the navigation, hero, About section, menu cards, order form, feedback form, team, contact information, links and footer.

HTML + CSS

HTML answers “What is on the page?” CSS answers “How should it look?” Together they create the final interface.

Semantic HTML

Elements such as header, nav, main, section, article and footer communicate the purpose of content and improve structure and accessibility.

03 / HTML FORMS

How the forms work.

<form>

Groups controls that collect user information. OPENNZO uses an order form and a feedback form.

<label>

Provides a readable name for a control. Its for value connects to the input's id.

<input>

Collects different data types. OPENNZO demonstrates text, email, telephone, number, time, radio and checkbox inputs.

<select> + <option>

Creates dropdown choices such as pizza, size and crust selection.

<textarea>

Collects longer text such as delivery instructions and feedback.

<fieldset> + <legend>

Groups related controls and gives the group a meaningful title, such as Size or Extras.

<button>

Creates the action control. OPENNZO uses submit buttons for demonstration; no backend processes the data.

Form attributes

required makes a field mandatory; name identifies submitted data; type defines the control type; placeholder gives a hint; value supplies a control value.

<label for="email">Email</label> <input id="email" name="email" type="email" placeholder="you@example.com" required>

04 / CSS FUNDAMENTALS

What is CSS?

Cascading Style Sheets

CSS stands for Cascading Style Sheets. It controls the visual presentation of HTML elements.

CSS syntax

.menu-card {
  padding: 20px;
  border-radius: 18px;
  transition: transform .3s ease;
}

The selector chooses an element; properties define what changes; values define how it changes.

Layout

OPENNZO uses Flexbox for alignment and one-dimensional layouts and CSS Grid for structured card layouts such as the pizza menu.

Responsive design

Media queries change layout rules for smaller screens so the site adapts to desktop, tablet and mobile without JavaScript.

Visual design

CSS controls typography, colors, backgrounds, spacing, borders, radius, shadows and the OPENNZO visual hierarchy.

Interaction

Transitions, transforms, pseudo-classes and CSS animations create smooth interactions without a JavaScript animation library.

06 / HTML ATTRIBUTES

Attributes explained.

id

Uniquely identifies an element. OPENNZO uses IDs such as menu and form-control IDs.

class

Reusable styling hook, for example class="pizza-card".

href

Defines an anchor destination, for example href="#orders".

src

Defines an image source.

alt

Provides alternative text for images and supports accessibility.

type

Defines an input/button type such as email, radio, checkbox or submit.

name

Identifies form data controls.

placeholder

Shows a hint before the user enters data.

required

Uses browser validation to require a value.

value

Sets the value represented by a control.

for

Connects a label to the element whose id matches it.

08 / PRESENTATION GUIDE

Explain it confidently.

Website structure

Navigation → Hero → About → Menu → Pizza Orders → Feedback → Team → Contact → separate documentation pages.

Why no JavaScript?

The project intentionally demonstrates what can be achieved with HTML5 and CSS3 fundamentals. Forms are demonstrations and do not have a backend.

Responsive design

Media queries adapt grids, navigation, forms, typography and spacing for different screen sizes.

Accessibility

Meaningful alt text, labels, heading hierarchy, readable contrast, semantic HTML and visible focus states are used to improve usability.

Short teacher answer: “OPENNZO is a Web Programming practical project. We used HTML5 to create the semantic structure and CSS3 to design the interface, layouts, responsiveness and interactions. We used forms to demonstrate common HTML controls and attributes, and we intentionally avoided JavaScript so the core HTML and CSS concepts remain clear.”
