01 / PROJECT

What is OPENNZO?

OPENNZO is a demo pizza restaurant webpage created by the OPENNZO Team for a Web Programming practical and presentation. It combines a professional restaurant interface with an educational explanation of the technologies used to build it.

02 / PURPOSE

Project objective

The objective is to demonstrate how a complete responsive webpage can be structured with HTML5 and styled with CSS3 without JavaScript or a frontend framework.

03 / SOURCE CODE

About the source code

The project source is separated into index.html and style.css. HTML creates the structure and content. CSS creates the visual design, layout, responsiveness, transitions and animations. The GitHub repository is the authoritative source of the implementation.

04 / TECHNOLOGY

Technologies used

HTML5 — webpage structure, semantic elements, links, images and forms.
CSS3 — colors, typography, spacing, Grid, Flexbox, responsive design, transitions and CSS animations.

01 / FUNDAMENTALS

What is HTML?

Definition

HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure and content of webpages.

What HTML does

HTML tells the browser what content exists and what that content means. It creates headings, paragraphs, links, images, sections, forms and other webpage elements.

HTML in OPENNZO

OPENNZO uses HTML for the navigation, hero section, pizza menu, order form, feedback form, team cards, contact information, documentation and footer.

Simple presentation answer

“HTML is the structure of a webpage. It defines the content and meaning of elements, while CSS is used to control how those elements look.”

02 / PRESENTATION FUNDAMENTALS

What is CSS?

DEFINITION

Cascading Style Sheets

CSS stands for Cascading Style Sheets. CSS controls the visual presentation of HTML elements.

APPEARANCE

How it styles HTML

CSS controls colors, backgrounds, fonts, font sizes, spacing, borders, border radius, shadows and alignment.

LAYOUT

How it arranges content

OPENNZO uses Flexbox and CSS Grid to arrange navigation, feature cards, pizza cards, forms, team cards and documentation content.

RESPONSIVE

How it adapts

CSS media queries change layouts at smaller screen sizes so the webpage works on desktops, tablets and mobile devices.

INTERACTION

How it moves

CSS transitions and transforms create smooth hover effects, card elevation, image scaling and button interactions without JavaScript.

RELATION

HTML + CSS

HTML provides the structure; CSS provides the visual design. OPENNZO uses both together to create the final interface.

03 / FORMS

How the forms work.

Form

<form> groups controls used to collect information. OPENNZO has a pizza order form and a feedback form.

Label

<label> gives every control a clear name. The for attribute connects the label to an input's id.

Input

<input> collects different data. OPENNZO demonstrates text, email, telephone, number, time, radio and checkbox input types.

Select + option

<select> creates a dropdown and <option> provides the choices, such as pizza selection, size and crust.

Textarea

<textarea> collects longer text, such as delivery instructions and customer feedback.

Button

<button type="submit"> creates the form submission action. In this project it is a demonstration; there is no backend.

Fieldset + legend

<fieldset> groups related controls. <legend> gives the group a title, such as “Size” or “Extras”.

Useful attributes

required makes a field mandatory. name identifies submitted data. type defines the input kind. placeholder gives a hint. value defines a control value.

Presentation answer

“Our forms demonstrate how HTML can collect structured user input. We use labels for accessibility, inputs for different data types, select and option for choices, textarea for longer messages, fieldset and legend for grouping, and a submit button for the action.”

05 / HTML ATTRIBUTES + CSS

Attributes &
CSS concepts.

id

Uniquely identifies an element. OPENNZO uses IDs for section targets such as #menu and for form-control connections.

class

Creates reusable styling hooks. Examples include class="pizza-card" and class="btn".

href

Defines where an anchor link goes, for example href="#orders".

src

Defines the source of an image in the img element.

alt

Provides meaningful alternative text for images and improves accessibility.

type

Defines an input or button type, such as text, email, radio, checkbox or submit.

name

Identifies form data values.

placeholder

Shows helpful example text before the user enters a value.

required

Uses built-in HTML validation to require important information.

value

Provides a predefined value for a control, such as a selected radio option.

Colors
