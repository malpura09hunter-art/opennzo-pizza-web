02 • HTML

What is HTML?

HTML means HyperText Markup Language. It describes the structure and meaning of webpage content.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>OPENNZO</title>
</head>
<body>
    <h1>OPENNZO</h1>
</body>
</html>
Basic structure

<html> contains the document, <head> contains metadata and resources, and <body> contains visible content.

06 • CSS

What is CSS?

CSS means Cascading Style Sheets. It controls the appearance, spacing and layout of HTML elements.

:root {
    --accent: #e4572e;
}

.btn-primary {
    background: var(--accent);
    color: #fff;
}
CSS structure

A selector chooses an element, a property describes what is being changed, and a value specifies how it should look.

10 • EFFECTS

Hover, transitions and animations

.btn-primary:hover {
    transform: translateY(-3px);
}

.pizza-card:hover {
    transform: translateY(-8px);
}

transition: transform .25s ease;

animation: float 5s ease-in-out infinite;
How the effect works

:hover changes styling when the pointer is over an element. transition makes the change smooth, while transform moves or scales an element. The project also uses CSS animations such as floating and marquee effects.

11 • RESPONSIVE DESIGN

Responsive OPENNZO

Media queries change the layout when the available screen becomes smaller.

@media (max-width: 900px) {
    /* layout adjustments */
}

@media (max-width: 700px) {
    /* smaller-screen adjustments */
}

The project's stylesheet contains responsive breakpoints that change grids, navigation, forms, typography and spacing so the pages remain usable on smaller screens.
