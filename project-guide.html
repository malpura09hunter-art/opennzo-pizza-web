02 • HTML

What is HTML?

HTML stands for HyperText Markup Language. HTML is used to create the structure of webpages. 

<!DOCTYPE html>

<html lang="en">

<head>
    <title>OPENNZO</title>
</head>

<body>

    <h1>OPENNZO</h1>

    <p>
        Fresh. Hot. Unforgettable.
    </p>

</body>

</html>
Basic structure

The document declaration identifies the document as HTML5. The <html> element contains the document, while <head> contains metadata and <body> contains the visible webpage content.

06 • CSS

What is CSS?

CSS stands for Cascading Style Sheets. CSS controls how HTML elements look and how they are arranged on the page. 

.example {
    color: #f4eee5;
    background: #171614;
    padding: 20px;
}
CSS structure

.example is the selector. color, background and padding are properties. Their assigned values control the appearance of the selected element.

09 • RESPONSIVE DESIGN

Making OPENNZO responsive

Media queries allow the layout to change according to the available screen width. 

@media (max-width: 850px) {

    .cards {
        grid-template-columns: 1fr 1fr;
    }

}

@media (max-width: 560px) {

    .cards {
        grid-template-columns: 1fr;
    }

}
How it works

On larger screens the cards can appear in multiple columns. At smaller widths, the CSS changes the Grid so the content fits mobile screens.
