01 • PROJECT INTRODUCTION

What is OPENNZO?

OPENNZO — Fresh. Hot. Unforgettable. is a pizza restaurant website created as a Web Programming practical and presentation project. The restaurant interface demonstrates a real product-style UI, while the documentation explains the HTML5 and CSS3 techniques used to build it.

PROJECT

OPENNZO Pizza

Premium restaurant concept with separate pages for the complete experience.

TECHNOLOGY

HTML5 + CSS3

Semantic HTML provides structure. CSS controls layout, typography, colour, responsiveness and interaction.

PURPOSE

Web Programming

Designed to be demonstrated to a teacher and explained tag-by-tag and concept-by-concept.

Say this to the teacher:

“OPENNZO is a pizza restaurant presentation website. We used HTML5 to create the structure and CSS3 to design the interface, including responsive layouts, forms, cards, navigation, transitions and typography.”

05 • FORMS

How the Order & Feedback forms work

Forms are especially important for the practical because they demonstrate multiple HTML elements and attributes working together.

FORM

<form>

Container for controls. It groups the customer's data-entry fields into one logical interaction.

LABEL

<label>

Names a control. The for attribute connects the label to a matching input id.

INPUT

<input>

Collects text, email, telephone, number, time, radio and checkbox values depending on its type.

SELECT

<select> + <option>

Creates dropdown choices such as pizza, size and crust.

GROUP

<fieldset> + <legend>

Groups related controls, such as pizza size or extras, with a meaningful caption.

LONG TEXT

<textarea>

Collects multi-line content such as special instructions or feedback.

Important:

“The forms are demonstration forms. HTML provides the controls and browser validation attributes; there is no restaurant backend or database processing.”

08 • CSS REFERENCE

How CSS creates the OPENNZO UI

Selectors

Element selectors target tags; class selectors such as .hero style reusable components; ID selectors target unique elements.

Box Model

Every element is built from content, padding, border and margin. OPENNZO uses these to control spacing and card proportions.

Flexbox

Used for one-dimensional alignment such as navigation, button groups and card rows.

CSS Grid

Used for two-dimensional layouts such as pizza cards, team cards and feature grids.

Transitions

Make hover/focus changes smooth instead of instant.

Transforms

Effects such as scale() and translateY() create subtle card/image movement.

Typography

Properties such as font-size, font-weight, line-height and letter-spacing create hierarchy.

Media Queries

Change layouts at smaller widths so the separate pages work on phones, tablets and desktops.

CSS Variables

Reusable custom properties keep colours, spacing and other design values consistent.

10 • PRESENTATION MODE

Questions your teacher can ask

What is HTML?

HTML stands for HyperText Markup Language. It provides the structure and meaning of webpage content.

What is CSS?

CSS stands for Cascading Style Sheets. It controls presentation: layout, colours, typography, spacing, responsive behaviour and visual effects.

Why HTML5?

HTML5 provides modern semantic elements such as header, nav, main, section, article and footer.

Why CSS Grid?

Grid is useful when content needs rows and columns, such as the menu and team cards.

Why Flexbox?

Flexbox is useful for aligning items along one direction, such as navigation and button groups.

Why no JavaScript for the restaurant UI?

The restaurant pages are intentionally built around HTML5 and CSS3 fundamentals. A small access script exists only for the custom entrance lock.

Closing answer:

“OPENNZO demonstrates how a complete multi-page website can be structured with semantic HTML and designed with CSS. Each page has a clear purpose, the forms demonstrate HTML controls and accessibility, CSS Grid and Flexbox create the responsive layouts, and the documentation lets us explain the actual implementation rather than only theory.”
