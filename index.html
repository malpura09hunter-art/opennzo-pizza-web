PRESENTATION GUIDE

How OPENNZO
was built.

A concise explanation you can use during the Web Programming presentation.

01

Introduction

OPENNZO is a modern pizza restaurant interface created to demonstrate practical HTML5 and CSS3 concepts.

02

Objective

The objective was to build a polished real-world website while keeping the implementation simple enough to explain.

03

Technologies

HTML5 provides structure and semantic meaning. CSS3 provides layout, visual design, responsiveness and animation.

04

Website Structure

Navigation → Hero → About → Menu → Orders → Feedback → Team → Contact → Code Details → Explanation → Footer.

05

HTML

Semantic HTML elements organize content into meaningful sections, headings, articles, forms and navigation.

06

CSS

CSS controls typography, color, spacing, Grid, Flexbox, cards, responsive layouts, transitions and transforms.

07

Forms

The order and feedback forms demonstrate labels, inputs, selects, radio buttons, checkboxes, textareas and buttons.

08

Navigation

Normal anchor links connect sections using IDs such as #home, #menu and #orders. No JavaScript is required.

09

Responsive Design

CSS media queries change grids, navigation, spacing and typography so the experience works across screen sizes.

10

Accessibility

Meaningful alt text, labels, heading hierarchy, contrast and keyboard-friendly controls improve usability.

11

Why No JavaScript?

The project intentionally demonstrates how far HTML5 and CSS3 can go without adding JavaScript.

12

Conclusion

OPENNZO combines a realistic restaurant interface with a clear academic explanation of core web programming concepts.

HTML Tags & Attributes

<header>

Defines introductory or navigational content.

<section>

Groups a thematic area of the page.

<article>

Represents an independent piece of content.

<form>

Groups controls used to collect user input.

class

Connects an element to reusable CSS rules.

id

Uniquely identifies an element and enables anchor links.

href

Defines the destination of a link.

src

Defines the source of an image.

alt

Provides meaningful alternative text for images.

required

Marks a form control as required by the browser.

CSS Concepts Used

Selectors

Target HTML elements for styling.

Box Model

Content, padding, border and margin control element space.

Flexbox

Aligns and distributes items along a flexible axis.

Grid

Creates the responsive two-dimensional pizza menu layout.

Positioning

Relative and absolute positioning create layered compositions.

Transitions

Make hover and focus changes smooth.

Transform

Scale and translate create subtle interactive movement.

Media Queries

Adapt the interface for different screen widths.
