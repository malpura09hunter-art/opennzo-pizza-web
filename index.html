WEB PROGRAMMING GUIDE

Understand
the code.

This section explains what HTML and CSS are, which tags and attributes OPENNZO uses, how the forms work, and why each technique appears in the project.

01 / HTML

What is HTML?

HTML (HyperText Markup Language) creates the structure and content of a webpage. In OPENNZO it creates the header, navigation, headings, paragraphs, images, menu cards, forms, team information and footer.

02 / CSS

What is CSS?

CSS (Cascading Style Sheets) controls how HTML looks and behaves visually. OPENNZO uses CSS for colors, typography, spacing, Grid, Flexbox, borders, shadows, responsive layouts, hover states, transitions and animations.

03 / RELATION

HTML + CSS

HTML is the structure and CSS is the presentation. HTML says what an element is; CSS decides how that element looks. Together they create the OPENNZO interface.

04 / SEMANTIC

Semantic HTML

Tags such as header, nav, main, section, article and footer describe the meaning and structure of content.

05 / LINKS

Anchor Links

OPENNZO uses <a href="#menu"> style links to move between sections without JavaScript. IDs identify the destination sections.

06 / IMAGES

Images & Alt Text

The img tag displays pizza imagery. The src attribute identifies the image source and alt provides meaningful alternative text.

HTML TAGS USED IN OPENNZO

<header>

Creates the introductory site header and navigation area.

<nav>

Contains the main navigation links.

<main>

Contains the primary webpage content.

<section>

Groups related content such as Menu and Team.

<article>

Creates independent cards such as pizzas and team members.

<h1>–<h3>

Creates a logical heading hierarchy.

<p>

Displays readable paragraph content.

<a>

Creates navigation and email links.

<img>

Displays pizza images with alt text.

<form>

Creates the order and feedback forms.

<label>

Describes and connects to form controls.

<input>

Collects text, email, phone, number, radio and checkbox input.

<select>

Creates dropdown controls.

<option>

Creates choices inside dropdowns.

<textarea>

Collects multi-line instructions and feedback.

<button>

Creates form submission actions.

<fieldset>

Groups related controls such as size and extras.

<legend>

Names a fieldset group.

<footer>

Contains final project information.

FORM TAGS & ATTRIBUTES

form

Wraps user-input controls and defines the form action.

label + for

Connects a visible label to an input ID for accessibility.

input type

Defines text, email, tel, number, radio and checkbox controls.

select + option

Creates structured dropdown choices.

textarea

Provides multi-line text input.

required

Makes important fields mandatory before submission.

name

Identifies the form value.

value

Defines the value submitted for a control.

placeholder

Provides helpful example text inside a control.

id

Uniquely identifies an element and supports label connections.

CSS CONCEPTS USED

Selectors

Target HTML elements for styling.

.class

Applies reusable styles to groups of elements.

#id

Targets a unique element or section.

Box Model

Controls content, padding, border and margin.

Flexbox

Aligns navigation, buttons and UI groups.

CSS Grid

Creates structured menu, team and documentation layouts.

SOURCE CODE EXPLANATION

How OPENNZO
was built.

01 / INTRODUCTION

About the project

OPENNZO is a premium pizza restaurant demonstration created for Web Programming practical and presentation purposes.

02 / SOURCE

About the source code

index.html contains the webpage structure and content. style.css controls the complete visual design, layout, responsiveness and CSS-only interactions.

03 / TECHNOLOGY

Why HTML5 + CSS3?

The project intentionally avoids JavaScript and frameworks so fundamental web-programming concepts can be demonstrated clearly.

04 / FORMS

How forms work

The order and feedback forms demonstrate form, label, input, select, option, textarea, fieldset, legend and button elements with useful attributes such as required, name, id and type.

05 / RESPONSIVE

Responsive design

CSS media queries change grids and navigation so the same project works across desktop, tablet and mobile screens.

06 / ACCESSIBILITY

Accessible structure

Meaningful alt text, labels, heading hierarchy, semantic elements, visible focus states and descriptive controls improve usability.

07 / NAVIGATION

Anchor navigation

Links use section IDs such as #menu and #orders so the page can navigate without JavaScript.

08 / CONCLUSION

Final result

OPENNZO combines a professional restaurant interface with a clear academic explanation of the HTML5 and CSS3 techniques used to create it.
